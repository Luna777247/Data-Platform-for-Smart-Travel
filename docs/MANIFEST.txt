KEY ARCHITECTURE COMPONENTS
================================================================================

Pipeline Lifecycle:
  CREATED → REGISTERED → SCHEDULED → QUEUED → INITIALIZING
  → RUNNING → VALIDATING → BRONZE → SILVER → GOLD → COMPLETED

Data Lakehouse:
  Bronze (Raw JSON)
    ↓ (Normalize, Validate)
  Silver (Parquet, Canonical Schema)
    ↓ (Enrich, Merge, Deduplicate)
  Gold (Business-Ready, Indexed)

Core Collections:
  - source_registry: Data source management
  - pipeline_registry: Pipeline definitions
  - pipeline_execution: Execution history
  - master_poi: Unified POI data
  - poi_reviews: Aggregated reviews
  - data_quality_reports: Quality metrics

Key Features:
  ✓ State machine pipeline lifecycle
  ✓ Automatic retry with exponential backoff
  ✓ Checkpoint-based recovery
  ✓ Entity resolution & deduplication
  ✓ Real-time quality monitoring
  ✓ Data lineage tracking
  ✓ Multi-source data unification

  → Bronze Storage (raw_20260508_120000.json)

  → Normalization

COMMON QUERIES
================================================================================

Find POI Near Location:
  db.master_poi.find({
    location: {
      $near: {
        $geometry: { type: "Point", coordinates: [139.7454, 35.6586] },
        $maxDistance: 5000
      }
    }
  }).limit(10)

Full-Text Search:
  db.master_poi.find({ $text: { $search: "tokyo tower" } })

Filter by Category:
  db.master_poi.find({ city: "tokyo", category: "restaurant" })
               .sort({ business_score: -1 })

View Execution History:
  db.pipeline_execution.find({ pipeline_name: "osm_pipeline" })
                      .sort({ started_at: -1 })
                      .limit(10)
